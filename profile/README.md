<h2>设备清单：五类，按必要性排序</h2>
<p>搭建一台住宅 IP 服务器，需要的设备并不多。按必要性排：主机、网络接口、路由器或网关、供电与散热、以及可选的监控与备用。</p>
<p>很多人一开始就买一堆设备，实际用不上的占一半。先按「最小可用」配一套，跑通之后再补，比一次配齐更省钱也更清楚自己需要什么。</p>

<h2>第一类：主机</h2>
<p>这类用途的主机不需要强性能。低功耗处理器、两三个 G 内存、一块小固态就够，因为主要工作是转发而不是计算。</p>
<p>更该关心的是两点：散热是否稳定、能不能长期开机。家用级设备长时间高负载运行容易出随机故障，选的时候优先看稳定性而不是跑分。</p>

<h2>第二类：网络接口与交换机</h2>
<p>如果只有一条线路，单网卡就够。如果要接多条线路或做双出口，建议双网卡，或者用一台支持 VLAN 的交换机在单口上划分。</p>
<p>交换机不是必需品，但它能让接线更清晰。设备多了之后，没有交换机就得靠网线拼，排障时会很痛苦。</p>

<h2>第三类：路由器或网关</h2>
<p>如果主机本身承担网关角色，路由器可以简化；如果要多设备分流，一台支持策略路由的路由器会省很多事。</p>
<p>选购时确认三项：能否配置多地址、是否支持策略路由、有没有链路健康检测。第三项决定了故障时能不能自动切换。</p>

<h2>第四类：供电与散热</h2>
<p>这一项最容易被忽略，却最影响长期稳定。建议配一个小功率不间断电源，避免短时断电导致设备重启后服务没起来。</p>
<p>散热上，别把设备塞在密闭空间里。过热导致的故障往往表现为「随机掉线」，查日志找不到明确原因，非常耗时间。</p>

<h2>第五类：监控与备用</h2>
<p>监控可以是简单的定时探测加告警，不必上复杂系统。备用是一台能临时顶上的设备，或者一条备用线路。</p>
<p>备用设备的实际使用频率很低，但它决定了「出问题时是几小时恢复还是几天」。对长期运行的业务，这笔投入通常值得。</p>

<h2>网络配置的四个部分</h2>
<p>一是接入配置：把线路配到设备上，确认能出网。二是地址配置：绑定需要的地址。三是路由与策略：决定哪个流量走哪个出口。四是访问控制：限制谁能用、从哪来。</p>
<p>四部分里第四项最容易被省略。设备长期在线，入口一旦暴露，很快会有陌生流量进来。</p>

<h2>什么可以省，什么不能省</h2>
<p>可以省：高配 CPU、大容量硬盘、多余的网络接口。不能省：散热、供电稳定性、以及一台能顶上的备用设备。</p>
<p>判断依据是「这项影响的是性能还是可用性」。性能过剩只是浪费钱，可用性不足会直接导致业务中断。</p>

<h2>把所有设备列成一张清单，标上替换成本</h2>
<p>设备清单不只是采购用，运维时也用得上。建议每项设备标注「坏了之后多久能替换」。路由器坏了可能当天就能换，专用电源坏了可能要等一周。</p>
<p>标完之后你会知道哪些该备件、哪些不用。备件不需要买贵的，能顶几天就够，它能避免的是一次长达一周的中断。</p>
<h2>常见问答</h2>
<h3>一定要买专用设备吗？</h3>
<p><strong>答：</strong>不必。低功耗小主机就能胜任，很多人用旧电脑改造也行。</p>
<h3>需要多贵的交换机？</h3>
<p><strong>答：</strong>普通千兆交换机够用。需要 VLAN 时才考虑网管型。</p>
<h3>不间断电源有必要吗？</h3>
<p><strong>答：</strong>长期运行的场景建议配。短时断电导致的恢复问题比想象中麻烦。</p>
<h3>备用设备怎么选？</h3>
<p><strong>答：</strong>能跑同样的配置即可，不必同型号。关键是配置能快速套用。</p>
